# Git delivery

- Inspect branch and worktree before changing or staging files; preserve unrelated and unowned work.
- Commit only when requested or project policy requires it, with focused commits and the established identity without changing global/local configuration.
- Push, publish, open or merge a PR, deploy, or otherwise affect remote state only with explicit authorization.
- Report commit identifiers and final staged/unstaged state accurately. Never claim a clean tree if changes remain.
